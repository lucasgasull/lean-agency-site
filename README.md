# Site Lean Agency

Site institucional da Lean Agency, publicado em https://lean-agency.netlify.app.

- `index.html`: página principal (HTML, CSS e JS no mesmo arquivo)
- `obrigado/`: página exibida depois do envio do formulário
- `js/`: GSAP, ScrollTrigger e Lenis (animações e rolagem suave)
- `netlify.toml`: configuração de publicação (pasta raiz, sem build)

Cada alteração enviada para a branch `main` é publicada automaticamente pelo Netlify.
